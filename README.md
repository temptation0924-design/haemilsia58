# 해밀시아58 홈페이지

해밀시아58 프라이빗 촬영 스튜디오 소개 홈페이지.

## 스택

- React 19 + TypeScript + Tailwind CSS 4 + Vite
- Framer Motion (애니메이션)
- Cormorant Garamond + Noto Sans KR + Playfair Display (타이포그래피)

## 주요 섹션

- Hero — 풀스크린 대표 이미지
- About — 스튜디오 소개 (전용면적 100평, 대지면적 350평)
- Space — 공간 미리보기 비대칭 그리드
- Features — Why HAEMILSIA 58
- Pricing — 이용 요금 안내 (A/B/C타임, 올데이, 풀타임)
- Gallery — 비대칭 그리드 갤러리 (라이트박스)
- Location — 찾아오는 길 (강남 기준 경로 안내)
- CTA — 예약 유도
- Footer — 사업자 정보 포함

## 로컬 실행

```bash
pnpm install
pnpm run dev
```
